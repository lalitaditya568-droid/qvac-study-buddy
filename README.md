# QVAC Study Buddy

A private, on-device AI study assistant powered by Tether's QVAC SDK.

## Features

- Ask study questions through a simple web interface
- AI inference runs locally on the user's device
- Uses the Qwen3 0.6B Q4 model
- No cloud AI API is required for inference
- Lightweight Node.js server
- QVAC SDK integration using `loadModel()` and `completion()`

## Tech Stack

- Node.js
- JavaScript
- QVAC SDK 0.19.1
- Qwen3 0.6B Q4
- HTML/CSS/JavaScript

## Requirements

- Windows 10 or newer
- Node.js 22.17 or newer
- npm 10.9 or newer
- Vulkan 1.4 or newer
- At least 4 GB RAM recommended
